# AI-Powered Student Performance Analysis & Prediction

## Project Overview

This project demonstrates how Data Analytics and Artificial Intelligence can be used to analyze student learning patterns and predict potential academic risk. It uses Python and machine learning to explore factors such as study hours, attendance, assignment completion, previous scores, sleep hours, and screen time.

## Objectives

* Analyze student performance indicators.
* Perform data cleaning and exploratory data analysis (EDA).
* Create visualizations to identify patterns and trends.
* Build a Random Forest classification model to predict academic risk categories.
* Evaluate model performance using accuracy, precision, recall, and F1 score.
* Generate insights that may help guide academic support.

## Technologies Used

* Python
* Pandas and NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Generate a sample student dataset.
2. Check missing values, duplicates, and data quality.
3. Perform exploratory data analysis.
4. Create charts to compare learning indicators and risk categories.
5. Train and evaluate a Random Forest classification model.
6. Demonstrate a prediction for a sample student.

## Dataset

The project uses a synthetic dataset of 1,000 student records generated within the notebook. No real student information is used.

## Expected Outcome

The project demonstrates an end-to-end data analytics and machine-learning workflow, including data preparation, visualization, model training, evaluation, and prediction.

## How to Run

1. Install Python 3.10 or later.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Launch Jupyter Notebook.
4. Open `Student_Performance_Analytics.ipynb`.
5. Select **Run All** to execute the project.

## Conclusion

This project showcases practical skills in Python programming, data analysis, data visualization, and machine learning. The results are illustrative because the dataset is simulated and should not be used for real academic decisions.
